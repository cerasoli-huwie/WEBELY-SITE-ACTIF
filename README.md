## 💻 LE SITE INTERNET WEBEL Y ACQUISITION SYSTEM

### Caractéristiques Techniques
* **Performance :** Score visé de **100/100 sur Google PageSpeed Insights**.
* **Zero Bloat :** Aucun framework lourd (pas de React/Next.js/Tailwind de 500 Ko). Chargement pur en < 0,5 seconde.
* **Typographie & Icônes :** Polices système natives (inter-compatibilité iOS/macOS/Windows/Android) et icônes SVG intégrées en ligne (zéro requête réseau externe bloquante).
* **Responsive Total :** Mobile-first, adapté du smartphone 360px jusqu'aux écrans 4K.

### Fonctionnalités Interactives
1. **Sélecteur de Métier en Direct :** Permet au visiteur d'adapter toute la page à sa spécialité (*Rénovation générale*, *Pompe à chaleur / HVAC*, *Toiture & Isolation*, *Électricité & Solaire*).
2. **Simulateur de Formulaire Qualifiant Multi-Étapes :** Test grandeur nature des questions de filtrage (Projet, Code postal local, Typologie de bâtiment, Échéance, Budget, Coordonnées) avec simulation de soumission et notification instantanée.
3. **Pipeline CRM Kanban Dynamique :** Visualisation des opportunités en 4 colonnes (*Nouveau*, *Contacté/RDV*, *Devis envoyé*, *Chantier signé*).
4. **Calculateur de Rentabilité ROI Transparent :** Démonstration par le calcul qu'un seul chantier signé sur le trimestre amortit à 100% l'installation et les honoraires mensuels.
5. **Modal d'Audit de Faisabilité Géographique :** Capture des demandes de rendez-vous de diagnostic commercial (15 min).

## 🚀 COMMENT VISUALISER ET UTILISER LES FICHIERS

### 1. Ouvrir le site internet localement
Double-cliquez simplement sur le fichier `index.html` pour l'ouvrir dans n'importe quel navigateur, ou lancez un serveur local rapide :
```bash
# Avec Python :
python3 -m http.server 8080

# Ou avec Node.js (npx) :
npx serve .
```
Puis accédez à `http://localhost:8080` dans votre navigateur.

### 2. Imprimer / Exporter le Contrat en PDF
1. Ouvrez le fichier `contracts/CONTRAT_WEBELY_DOSSIER_COMPLET_IMPRESSION.html` dans Chrome, Safari ou Edge.
2. Cliquez sur le bouton bleu **« Imprimer / Exporter en PDF »** situé dans la barre supérieure (ou faites `Cmd + P` / `Ctrl + P`).
3. Choisissez l'imprimante **« Enregistrer au format PDF »**.
4. Cochez **« Graphiques d'arrière-plan »** pour préserver les couleurs et encadrés.
5. Vous obtenez un dossier contractuel prêt à être envoyé pour signature électronique (DocuSign, Yousign, Adobe Sign) ou paraphé manuellement.
